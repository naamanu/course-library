# Course Library

A static library of eight courses with search, chapter navigation, section outlines, themes, and browser-local reading progress.

## Preview locally

Run `python3 -m http.server 8080 --bind 127.0.0.1` in this folder, then visit http://localhost:8080.

## GitHub Pages

Publish the repository root from the `main` branch in Settings → Pages. `.nojekyll` serves these files directly, without a build step or package installation. All paths are relative and work under a project URL such as `/course-library/`.

The export contains 436 lessons across eight courses. Course content and attribution belong to their original authors. No redistribution license is granted by this repository. Original ZIPs, saved website captures, and videos are excluded.

Saved editor examples contain only code captured in the source HTML; they do not execute code. External reference links require internet access. Reading progress is stored on the current browser origin and is not synchronized with other devices or the original local preview.
